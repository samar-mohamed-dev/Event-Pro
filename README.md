# Event Pro

## Conference Management Platform

Event Pro is a web-based conference management platform designed to help
organizers and participants manage conferences, registrations, sessions,
and participant interactions digitally.

## Features

- User Registration and Login
- Conference Management
- Conference Registration
- Session Management
- Participant Management
- Ticket and Booking Management

## Technologies

- HTML5
- CSS3
- JavaScript
- Bootstrap
- PHP
- MySQL

## Project Structure

- `backend/` - Backend files and database
- `css/` - Stylesheets
- `img/` - Images and assets
